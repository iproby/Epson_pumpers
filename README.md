## ✨ Что умеет программа?

* 🧽 **Сброс счётчика памперса (отработанных чернил)**  
  Когда принтер блокируется и мигает красными индикаторами («Срок службы впитывающей чернила подкладки истёк»), программа обнуляет счётчик в один клик.
* 📊 **Точный уровень чернил и статус принтера**  
  Узнавайте точный процент остатка чернил каждого цвета и текущее состояние принтера прямо по Wi-Fi.
* 🔍 **Автоматический поиск принтеров в сети**  
  Программа сама найдёт ваш принтер в домашней сети или офисе — вам не нужно искать его IP-адрес вручную.
* 🚿 **Прочистка сопел и печать тестов**  
  Запускайте обычную или усиленную прочистку печатающей головки, а также печатайте тест дюз без установки громоздких драйверов.
* ⏱️ **Настройка таймера автовыключения**  
  Регулируйте время автоматического перехода в режим сна и выключения устройства.
* 🇷🇺 **Поддержка русского и английского языков**  
  Полностью локализованный, интуитивно понятный графический интерфейс.

## 🚀 Как пользоваться: пошаговая инструкция (4 шага)

1. **Скачайте и запустите программу** на вашем компьютере.
2. **Подключитесь к принтеру**:
   - Убедитесь, что ваш компьютер и принтер подключены к одной Wi-Fi сети.
   - Нажмите кнопку **«Найти принтер»** (программа определит IP и модель) или введите IP-адрес вручную.
   - Нажмите **«Подключиться»**.
3. **Сбросьте памперс**:
   - Перейдите на вкладку **«Обслуживание»**.
   - Нажмите кнопку **«Сбросить счётчик памперса»** и подтвердите действие.
4. **Перезагрузите принтер**:
   - Выключите принтер кнопкой на корпусе и включите снова.
   - Принтер разблокирован и готов к печати! 🎉

## 📋 Поддерживаемые модели

Программа поддерживает большинство струйных принтеров и МФУ **Epson** со встроенным Wi-Fi или сетевым портом:
- **Серия L / EcoTank («Фабрика печати»)**: L3150, L3160, L4150, L4160, L805, L3050, L3070 и многие другие.
- **Серия XP (Expression Home / Premium)**: XP-200, XP-205, XP-215, XP-305, XP-405, XP-600 и др.
- **Серия WF (WorkForce)**: WF-2530, WF-2630, WF-7000 и др.
- **Серия Stylus Office / Photo** со встроенным сетевым адаптером.

*(Примечание: некоторые отдельные версии заводских прошивок 2024–2025 года могут иметь отключённый производителем сетевой протокол EEPROM).*

## ⚠️ Важное предупреждение

> **Пожалуйста, обратите внимание!**  
> Сброс счётчика снимает **программную блокировку** принтера. Если ваш принтер уже отпечатал много тысяч листов, обязательно физически проверьте состояние впитывающей войлочной прокладки (памперса) в задней/нижней части принтера — промойте её, замените или выведите дренажную трубку в наружную емкость, чтобы чернила не переполнили корпус принтера.

<summary>🛠️ Информация для разработчиков и запуск из исходного кода</summary>

### Запуск через Python:
```bash
git clone https://github.com/iproby/Epson_pumpers.git
cd Epson_pumpers
python3 -m venv venv
source venv/bin/activate  # в Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

### Сборка собственных дистрибутивов:
- **macOS / Linux**: `python build_desktop.py --clean`
- **Windows**: `build_windows.bat` или `python build_desktop.py --clean`

### Консольный режим (CLI):
```bash
python main.py --cli -m L3150 -a 192.168.1.50 --reset_waste_ink
```
